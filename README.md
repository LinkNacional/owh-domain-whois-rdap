## Descrição

**OWH Domain WHOIS RDAP** é um plugin WordPress moderno para verificação de disponibilidade de domínios usando exclusivamente o protocolo RDAP (Registration Data Access Protocol), abandonando o protocolo WHOIS legado. O plugin oferece uma experiência completa com interface intuitiva, blocos Gutenberg avançados e informações detalhadas de WHOIS/RDAP.

> **Protocolo RDAP Moderno**: Utiliza apenas RDAP (JSON) para consultas mais rápidas e precisas.

> **Validação Oficial de TLDs**: Valida extensões de domínio usando a lista oficial da IANA (`data.iana.org/rdap/dns.json`).

> **Múltiplos TLDs**: Compatível com centenas de extensões oficiais de domínio.

### Como Funciona

1. **Entrada do Domínio**: O usuário digita o nome do domínio no formulário de busca
2. **Validação do TLD**: O plugin valida a extensão contra a lista oficial da IANA
3. **Consulta RDAP**: Se válido, realiza a consulta RDAP ao servidor apropriado
4. **Exibição do Resultado**: Mostra o status de disponibilidade com informações detalhadas

### Para Quem é Ideal

- **Empresas de Hospedagem**: Funcionalidade de busca de domínios para serviços de hosting
- **Registradores de Domínio**: Integração com sistemas de registro de domínios
- **Agências Web**: Verificação de disponibilidade de domínios para clientes
- **Desenvolvedores**: Implementação moderna de RDAP para serviços de domínio
- **Profissionais de TI**: Coleta confiável de informações de domínio

### Destaques Técnicos

- **Protocolo RDAP**: Substituto moderno para o WHOIS legado (porta 43)
- **Respostas JSON**: Dados de domínio estruturados e legíveis por máquina
- **Integração IANA**: Sincronização oficial da lista de TLDs
- **Arquitetura Limpa**: Compatível com PSR-4 e injeção de dependência

## Como instalar?

1. Acesse o painel de administração do WordPress e vá para **Plugins > Adicionar Novo**.
2. Pesquise por "OWH Domain WHOIS RDAP".
3. Encontre o plugin, clique em **Instalar Agora** e depois em **Ativar**.
4. Pronto! Acesse **OWH RDAP Settings** para configurar as páginas de busca e resultados.
